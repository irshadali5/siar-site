Traditional messaging apps depend on AWS, cellular towers, and central DNS. SIAR operates directly peer-to-peer over physical radio waves.

Zero Infrastructure & Sovereign Identity

No central servers, identity registrars, or phone number databases. Cryptographic identities are self-sovereign Ed25519 keypairs discovered directly over local physical radio.

Core Spec: Spec 02 • Self-Sovereign Trust

Delay-Tolerant Networking (DTN)

Store-carry-forward routing bridges physical air-gaps. Messages travel via physical motion of vehicles, walking couriers, and solar relays during total blackouts.

DTN Standard: Bundle Protocol v7 (RFC 9171)

Persist-Before-Send Transactional Outbox

Zero data loss across unexpected battery cuts. Every message, state mutation, and media chunk is committed to an embedded SQLite Write-Ahead Log before radio transmission.

MLS Post-Compromise Security

Step 1: Local Transactional Commitment (Persist-Before-Send)

Before any radio wave is transmitted, Alice's device signs the message payload with its ephemeral Ed25519 device key, encrypts it within the active OpenMLS tree ratchet (Epoch 4), and commits the transaction to an embedded SQLite Write-Ahead Log. If battery dies right now, zero data is lost.

CRYPTOGRAPHIC TRUST MODEL

Multi-Device Identity Without Central Registrars

How Spec 02 separates durable accounts from ephemeral hardware possession with zero private keys exported over the air.

TIER 1 • ROOT

Offline Account Root Key (Ed25519)

Lives in offline cold storage or hardware security modules (HSM). Signs only device certificates, directory updates, and root rotations. Never establishes radio sessions.

TIER 2 • RATCHET

Signed Device Directory & Monotonic Ratchet

Tracks active devices under strictly monotonic generation numbers ($G \to G+1$). Local trust stores reject older generations, making network rollback attacks cryptographically impossible.

TIER 3 • SCOPED

Granular Capability Bitmasks

Enforces least authority on hardware. Headless solar repeaters and vehicles receive blind relay keys with zero ability to read decrypted chats or add new devices.

TIER 4 • PAIRING

Zero-Knowledge Out-of-Band Pairing Ceremony

Dynamic QR codes and NFC payloads encode zero private keys. Devices execute an ephemeral X25519 Diffie-Hellman handshake verified by a 6-digit Short Authentication String (SAS).
