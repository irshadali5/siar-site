1. Executive Summary & Mission

SIAR (Survivable Identity & Autonomous Routing) is a zero-infrastructure, multi-transport, offline-first decentralized messaging and delay-tolerant networking (DTN) platform written in pure Rust with native Android (Kotlin/Jetpack Compose) and Desktop (Dioxus) clients.

The SIAR Web & Distribution Platform serves as the central public gateway, package repository, interactive simulation laboratory, verification authority, and survivable distribution hub for the entire SIAR ecosystem. It is engineered with three core mandates:

  1. Product Showcase & Education: Provide a modern, ultra-responsive visual showcase that articulates SIAR's zero-infrastructure mesh paradigm, cryptographic identity model, and off-grid emergency capabilities to end-users, organizations, and emergency responders.
  2. Universal, Verifiable Package Distribution: Host and distribute cryptographically verified native binaries, installers, mobile packages, container images, and repository feeds across 12+ operating systems and package ecosystems with SLSA Level 3+ provenance, reproducible build attestations, and automated signature validation.
  3. Survivable & Offline-First Operation: Function not only as a global cloud-native edge portal, but also as an air-gappable, zero-cloud distribution pack that can be self-hosted on local siar-emergency-node repeaters via Wi-Fi captive portals, local LANs, BitTorrent swarms, and Iroh P2P content-addressed blobs during complete internet blackouts.
